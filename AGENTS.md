# Libby quotes to notion page exporter Project

## Business Requirements

- A Gradio App that allows the user to upload a csv file which contains libby quotes and click on a button to create a notion page
- The Gradio App should be password gated
- The Gradio app should have a preview of the csv file (details in PRD.md)
- The Gradio app should also let the user know if the notion page creation is successful or not (details in PRD.md)

## Technical Details

- Tech stack is Gradio, Pandas, Notion API python module for now, for more information see PRD.md
